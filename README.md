## Entry

> Cursor blinks at three
> the log insists all is well
> I wrote the liar

67 characters, three lines, 5-7-5 syllables.

## How it works

`main.py` writes that exact haiku to `/output/entry.txt` and prints it to stdout. Deterministic — no input, no randomness, no network.
